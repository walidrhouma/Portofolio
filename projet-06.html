Projet de formation — Administrateur Systèmes & Réseaux

Interconnexion sécurisée de deux sites

Déploiement d'un environnement Active Directory

Mise en œuvre d'une maquette d'infrastructure permettant de raccorder un site distant au système d'information de l'entreprise.

Statut : Projet validé

Contexte

Dans le cadre d'une mise en situation professionnelle, la mission consistait à intégrer une entité distante au système d'information de l'entreprise.

L'infrastructure devait permettre une communication sécurisée entre les deux sites tout en assurant l'administration centralisée des utilisateurs et des postes de travail.

La solution a été conçue et testée dans un environnement virtualisé avec VirtualBox.

Objectifs

  • Installer et configurer Windows Server 2019.
  • Mettre en place Active Directory.
  • Créer les OU et les utilisateurs.
  • Configurer les GPO.
  • Mettre en œuvre un RODC.
  • Configurer un VPN inter-sites.
  • Automatiser une tâche d'administration avec PowerShell.

Environnement technique

  • Windows Server 2019
  • Windows 10
  • Active Directory Domain Services
  • RODC
  • GPO
  • pfSense
  • VPN
  • PowerShell
  • VirtualBox
  • Google Drive

Réalisations

Déploiement des serveurs

Installation et configuration des serveurs Windows Server nécessaires à l'infrastructure.

Active Directory

Mise en place de l'annuaire d'entreprise, création des unités d'organisation et des utilisateurs demandés dans le cadre du projet.

VPN inter-sites

Configuration d'un VPN permettant d'assurer la communication entre les deux sites.

GPO

Mise en place de stratégies de groupe afin d'administrer et de configurer les postes et utilisateurs de l'environnement.

RODC

Mise en œuvre d'un contrôleur de domaine en lecture seule pour le site distant.

Automatisation PowerShell

Développement d'un script PowerShell permettant d'automatiser la copie de données du serveur principal vers un stockage externalisé.

Résultats et validation

Le projet a été validé le 3 juillet 2024.

  • VPN configuré et fonctionnel.
  • OU et utilisateurs créés conformément aux besoins.
  • Script PowerShell fonctionnel.
  • Deux serveurs installés et configurés.

Compétences mises en œuvre

  • Administration Windows Server
  • Administration Active Directory
  • Configuration de GPO
  • Configuration VPN
  • Virtualisation
  • Automatisation avec PowerShell
